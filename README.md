## 📖 Project Overview

This project is an intelligent AI-powered customer support chatbot for a restaurant website.

It uses Retrieval-Augmented Generation (RAG) to answer customer questions based only on restaurant knowledge stored in Word documents and JSON menu files.

Instead of hallucinating, the chatbot retrieves relevant information from Pinecone Vector Database before asking Google's Gemini model to generate a response.

## ✨ Features

- AI-powered customer support
- Retrieval-Augmented Generation (RAG)
- Gemini 2.5 Flash
- Pinecone Vector Database
- LangChain Framework
- Restaurant menu search
- Conversation memory
- Flask REST API
- Responsive chatbot widget
- Docker-ready architecture
